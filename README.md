# 💳 Stripe Demo Integration

This project is a simple web application created to experiment with and learn how to integrate **Stripe payments** into a website.

It demonstrates how to implement basic payment functionality and understand the end-to-end flow of online transactions.

---

## 💡 Overview

The project was built as a **learning exercise** to explore:

* how Stripe works
* how to handle payments on the web
* how to connect frontend and backend payment flows

It included a working demo environment, which is no longer hosted due to maintenance costs.

---

## 🔑 Features

### 💳 Payment Integration

* Basic Stripe payment flow
* Handling payment requests from the frontend
* Communicating with Stripe API

---

### 🌐 Web Interface

* Simple UI to trigger payments
* Demonstrates a minimal checkout experience

---

### ⚙️ Backend Logic

* Payment session creation
* Secure communication with Stripe
* Handling responses and status

---

This project helped me understand:

* how to integrate Stripe into a web application
* how payment flows work (client ↔ server ↔ Stripe)
* how to securely handle payment-related operations
* basics of real-world payment systems
